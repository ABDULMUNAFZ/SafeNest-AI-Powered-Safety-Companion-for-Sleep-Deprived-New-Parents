# 🛡️ SafeNest AI

> **Your Intelligent Postpartum Safety Companion**

SafeNest AI is a voice-first healthcare platform designed to support sleep-deprived new parents during the postpartum journey. Unlike traditional baby-tracking applications, SafeNest focuses on reducing cognitive load, preventing caregiving mistakes, and improving the wellbeing of both the baby and the parent through AI-powered assistance.

---

## 🌍 Problem Statement

The postpartum period is one of the most challenging phases for new parents. Sleep deprivation, emotional stress, and mental fatigue often lead to:

- 💊 Incorrect medication dosage
- 🍼 Missed feeding schedules
- 🧷 Forgotten diaper changes
- 😴 Poor sleep tracking
- ❤️ Undetected signs of postpartum depression
- 🚨 Delayed response during emergencies

Existing parenting applications primarily focus on tracking baby activities. SafeNest AI goes beyond tracking by acting as an intelligent healthcare companion that actively assists parents in making safer decisions.

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/your-username/safenest.git
```

Go into the project

```bash
cd safenest
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
